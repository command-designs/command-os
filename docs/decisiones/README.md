# Decisiones

Decisiones no obvias: qué se decidió, por qué y qué se descartó, para no reabrirlas. Las anteriores
al 2026-10-07 están repartidas por `docs/` y `AGENTS.md` («Qué se probó y qué se descartó»).

Van en un archivo por quincena (las más nuevas, arriba en cada archivo). Una decisión nueva se añade
al archivo de su quincena y a este índice; al empezar una quincena nueva se crea su archivo.

Al citar una decisión desde el código o un documento, enlaza a su archivo y título, no solo a este índice.
